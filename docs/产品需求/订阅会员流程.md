# 订阅充值流程

按确认参考图保留以下节点及文案。已去掉“已存在会员套餐且处于会员期？”、“新套餐覆盖已开通会员套餐”及“跳过覆盖，直接更新会员数据”分支；支付成功后直接叠加到账方式到账会员权益，不在本产品流程中自行定义套餐覆盖。

### 固定文案

开通会员；选择对应会员套餐；周会员 / 月会员 / 季会员 / 年会员；立即购买；苹果支付；是否取消支付？；Toast：支付取消；是否支付成功？；Toast：支付失败；叠加到账方式到账会员权益；刷新页面数据。

### 接入边界

原型仅演示取消、失败及成功路径，不调用真实苹果支付、不授予真实会员。成功路径由服务端验证交易后执行；网络异常、待处理交易保留状态并允许后续同步，不在验证前展示已开通。具体套餐的变更生效遵循平台及实际商品配置，不在本流程假定新套餐覆盖旧套餐。
