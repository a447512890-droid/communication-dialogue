# 录音与转写技术说明

此文档只描述后台技术；用户页面及电话／复盘主流程以[业务流程图](整体技术实现流程图.md)为准。

## 录音回传

用户明确确认拨打；真实服务能力及录音授权校验通过后由电话服务采集录音，挂断后回传。服务端校验签名、call_id及重复回调，永久保存录音；用户点击开始转写后才排队。录音未生成或授权不满足时保留电话记录状态，不生成虚构转写、不启用复盘。

## 异步转写

使用豆包录音文件识别模型2.0，资源volc.seedasr.auc。服务端提交受控录音地址、保存任务ID并查询结果。配置show_utterances获取分句，enable_speaker_info=true开启单声道说话人分离；返回多少个说话人就保留多少个编号，按“说话人1、说话人2、说话人3……”展示，不自动映射为“我／对方”。

原文、分句、音频位置和转写版本独立保存；分句位置为第三方返回相对于录音起点的偏移，统一归一化为毫秒，不是客户端时间或服务端收包时间。修正原文产生新版本，不改写已有复盘快照。

## 状态与复盘

状态为录音待同步、待转写、处理中、成功、失败；客户端不判断系统电话是否未接通。有效录音默认待转写，用户点击开始转写才创建ASR任务；提示“转写完成后才可复盘”。失败保留原录音和任务信息，幂等重试。成功只更新实战电话记录，不自动关联演练。用户在复盘先选电话、再选关联演练、确认后创建分析任务。

## 时间记录

call_created_at为业务服务端创建拨打记录时的UTC时间；connected_at和ended_at取呼叫服务实际接通和结束事件时间，服务端校验保存；received_at如保存仅用于排查网络延迟。通话时长为ended_at减connected_at。客户端单调计时为界面估计，正式值以服务端事件核算为准，缺失事件标记未知，不据此推断系统电话未接通。显示日期按Asia/Shanghai格式化。

## 当前状态

当前网页未接入真实电话、录音回传及ASR。语音演练转写来自千问实时事件，属于另一链路，不能套用真实电话ASR事件。

## 手动刷新

电话记录详情转写区域提供“刷新状态”。只查询当前call_id的已有任务状态和已保存结果，不重新提交ASR、不生成新任务，不因刷新扣转写次数。仅转写中显示刷新，成功后隐藏；处理中刷新仍保持处理中；原型重新展示当前本机模拟状态，真实查询接口未接入。


## 录音转写接口说明

豆包录音文件识别2.0采用“提交任务 → 查询结果”，不需要提示词。接口由业务服务端调用，密钥不下发iOS客户端。

### 补充识别设置

| 参数 | 配置值 | 说明 |
| --- | --- | --- |
| request.enable_emotion_detection | true | 返回分句additions.emotion，情绪标签仅作辅助信息 |
| request.enable_gender_detection | true | 返回分句additions.gender；不据此判断我／对方 |
| request.sensitive_words_filter | 不传 | 默认保留原文；字段为配置字符串，不传false |
| request.enable_poi_fc | true | 地点、店名等地图领域辅助识别 |
| request.corpus.context | 本项目需要配置，传JSON字符串 | 提供业务上下文辅助识别；POI城市信息有实际数据时补充 |
| request.enable_music_fc | true | 歌名等音乐领域辅助识别 |
| request.show_speech_rate | false | 暂不启用语速信息 |
| request.show_volume | false | 暂不启用音量信息 |
| request.corpus.boosting_table_name / correct_table_name | 不传 | 暂不配置热词和替换词表 |
| callback / callback_data | 不传 | 暂不配置回调 |


[官方接口文档](https://docs.volcengine.com/docs/DoubaoVoice/AudioFileRecognitionStandardEdition?lang=zh)

系统通话结束后回到拨号键盘页，不弹出等待录音的toast。400录音传至我方服务器需要时间，期间在通话记录详情固定提示“若已完成通话，请等待录音同步。录音同步完成后，可手动转写并进行实战复盘。”，录音是否可用以服务端回传为准。

等待400录音期间状态为recording_pending，不显示开始转写；服务端确认录音可用后变为untranscribed，隐藏等待提示并显示开始转写。
