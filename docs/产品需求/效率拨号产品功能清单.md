## 演练

电话面试、咨询了解、沟通协商、自定义 → 设定目标 → 确认目标 → 沟通中 → 收齐尾部转写 → 演练结果。角色各20字、目的100字、背景100字、备注60字，五项输入合计最多300字；背景和备注可空。无效输入开始／提交置灰。最终提交检查每日额度，会员每日北京时间累计3600秒。

电话样式，查看对话在右下方、结束对话居中；无暂停、继续或提示按钮。转写保留我／AI及目标快照角色，不显示逐条时间。结果显示拼接后的目标回顾、转写及演练总结。总结模型doubao-seed-2-0-mini-260428，输入目标快照与speaker/text，输出overview及suggestions。

最近演练最多5条，空状态可预览；查看全部进入独立演练历史，不进入实战复盘列表。

## 实战

+86大陆手机号码拨号，右侧删除，号码有效才可呼叫。系统通讯录联系人选择页使用系统界面，原型仅占位，无App联系人档案及详情页。接通中与通话中独立预览，接通前不计通话时长。电话页仅常规通话信息与静音、扬声器、挂断；接通后秒数递增，达到1小时自动挂断。

服务端永久保存有效录音；用户手动点击开始转写后调用豆包录音文件识别2.0；无录音、未接通或转写未完成不可复盘。

## 复盘

实战电话列表 → 电话详情 → 选择关联演练 → 用户确认 → 对照结果。同一电话记录仅可完成一次复盘，已复盘的不显示在新增复盘的电话选择清单中，且无法重复复盘。关联演练仅展示已完成且未复盘过的记录，已复盘的不显示，每条演练仅可用于完成一次复盘。默认不选演练、不自动配对，不因挂断或转写成功自动分析；取消不创建关系。仅提交演练目标和实际通话转写，展示整体复盘及五维评分，统一使用雷达图展示五维评分；无折叠和结果页再练／重新选择／底部返回按钮，实战复盘模型尚未确定。

## 我的与订阅充值

账号名称及独立公开账号编号；会员有效期或非会员卡片点击进入订阅充值。周／月／季／年套餐，立即购买→苹果支付，取消／失败显示固定Toast，验证成功后叠加到账方式到账会员权益并刷新页面；不自定义套餐覆盖。

恢复购买按已确认流程：验证购买记录→确认最近充值账户→检查注销→重新获取订阅；注销账户提示无法恢复。隐私政策、用户协议、关于我们；注销入口灰色底部文字，协议10秒后可确认。无数据管理入口。
