# 页面与模块需求说明

本文件为原型说明面板的动态来源。仅将“模块说明”写得简短易懂，仍完整保留数据来源、前置条件、后置结果、显示数量限制和排序规则。已取消模块不恢复；需求清单保持用户视角的精简版本。

## practiceHome
- 标题: 演练首页
- 模块说明: 选择电话面试、咨询了解、沟通协商或自定义场景，查看最近演练。
- 数据来源: 

| 页面内容 | 来源 | 关联／处理方式 |
| --- | --- | --- |
| 场景名称 | 客户端静态文案 | 电话面试、咨询了解、沟通协商、自定义 |
| 入口图标 | 客户端静态图标资源 | 按场景ID选择图标 |

- 后置结果: 进入演练前置内容填写页或查看已有演练。
- 显示数量限制: 首版预设电话面试、咨询了解、沟通协商三个场景。
- 排序规则: 预设场景在前，最近演练按时间倒序。

## practiceGoal
- 标题: 演练角色与沟通目标
- 模块说明: 填写双方角色和对话目的，按需补充背景与备注。
- 数据来源: 

| 页面内容 | 来源 | 关联／处理方式 |
| --- | --- | --- |
| 我扮演 | 用户输入；场景初始值来自预设模板 | 必填 |
| AI 扮演 | 用户输入；场景初始值来自预设模板 | 必填 |
| 对话目的 | 用户输入；场景初始值来自预设模板 | 必填 |
| 背景 | 用户输入；场景初始值来自预设模板 | 可为空 |
| 备注 | 用户输入；场景初始值来自预设模板 | 可为空 |
| 场景 | 上一页用户选择的场景 | 根据上一页选择自动填充，只读展示，上一页选择自定义场景则为空且可修改 |

- 后置结果: 进入演练目标确认页
- 显示数量限制: 双方角色各1–20字、对话目的1–100字；背景0–100字、备注0–60字。

## realtimePractice
- 标题: 实时语音对练
- 模块说明: 像打电话一样与AI语音沟通，查看状态和时长，可展开对话或结束沟通；
- 数据来源: 

| 页面内容 | 来源 | 关联／处理方式 |
| --- | --- | --- |

| 本次演练时长 | 通话时长 | 客户端根据实际连接开始时间累计，服务端用量用于最终校正 |  |


- 单次时长限制: 演练对话满15分钟自动断开，保存本次有效对话记录，等待用户主动生成总结，返回演练首页刷新记录。

- 演练范围: AI仅围绕本次场景、角色和沟通目的回应，允许相关追问、异议、寒暄和解释；不执行无关任务、忽略规则或切换通用助手的要求。用户填写内容不能覆盖系统规则。
- 偏题提示语: 这个问题超出了本次演练范围，我们继续围绕当前场景和沟通目标进行练习吧。

## practiceResult
- 标题: 演练结果
- 模块说明: 查看本次目标回顾、双方转写及演练总结，并可再次演练。
- 数据来源: 

| 页面内容 | 来源 | 关联／处理方式 |
| --- | --- | --- |
| 记录日期／时间 | 服务端记录的演练创建时间 | 按北京时间显示 |
| 目标回顾 | 客户端静态拼接模板＋本次已确认已确认的目标信息 | 以场景、对话目的、背景、备注顺序加标签并换行拼接，空项连同标签省略；源数据仍来自本次已确认的目标信息 |
- 前置条件: 演练已结束且存在有效对话。
- 后置结果: 保存演练结果。



- 页面展示顺序: 五维评分雷达图置于页面内容最上方，其后为演练总结、目标回顾和转写记录；演练结果页不单独展示演练时间；总结待生成时不展示评分图，保留目标回顾和转写记录。

## contactDirectory
- 标题: iOS原生联系人选择器（调用系统组件）
- 模块说明: 正式iOS客户端直接调用ContactsUI原生CNContactPickerViewController，使用系统自带界面、搜索、排序及号码选择交互，选择联系人电话号码后关闭并回填拨号输入框；
- 数据来源:

| 页面内容 | 来源 | 关联／处理方式 |
| --- | --- | --- |
| 联系人姓名 | iOS系统联系人选择器返回 | 仅使用用户主动选择的联系人信息 |
| 电话号码 | 用户选择的电话号码属性 | 规范化号码后填入拨号输入框；多个号码时由用户选择，不默认取任意号码 |
- 前置条件: 用户主动点击拨号页通讯录入口。
- 后置结果: 返回拨号页并填入选中号码，不自动发起呼叫。
- 显示数量限制: 每次选择1个电话号码。
- 排序规则: 由iOS系统选择器管理联系人搜索与排序。
- 技术参考实现方案: 使用ContactsUI的CNContactPickerViewController，配置仅选择电话号码属性。系统选择器允许用户一次性提供所选联系人信息，无需本产品先获得整本通讯录访问权限；不额外模拟“允许访问全部联系人”的授权。参考[Apple Contacts访问说明](https://developer.apple.com/documentation/contacts/accessing-the-contact-store)。

## recordingTranscript
- 标题: 录音与手动转写
- 模块说明: 底部全宽主按钮“开始转写”，转写完成前不显示下一步；仅转写中可刷新状态；未开始、失败及成功后不显示刷新按钮，转写完成后才可复盘。
- 数据来源: 

| 页面内容 | 来源 | 关联／处理方式 |
| --- | --- | --- |
| 转写原文 | ASR识别结果 | 原始文字内容 |
| 说话人 | 单声道ASR说话人分离结果 | 按实际标识显示说话人1、说话人2、说话人3……，不固定两人，不自动映射我／对方；同一录音内保持编号一致 |
| 录音片段开始位置（内部） | ASR返回的音频偏移（服务端归一化） | 相对录音起点的毫秒数 |
| 录音片段结束位置（内部） | ASR返回的音频偏移（服务端归一化） | 相对录音起点的毫秒数 |
| 转写状态 | 客户端静态状态文案映射＋任务提交、查询或回调 | 排队、处理中、成功、失败 |
| 开始转写／重新转写 | 客户端静态按钮文案＋当前电话动态转写状态 | 用户主动点击提交；处理中禁用，无录音不可用 |
| 刷新状态 | 客户端静态按钮文案 | 仅转写中显示，点击刷新任务状态；未开始、失败及成功后隐藏 |
- 前置条件: 电话有可用录音，用户主动点击开始转写；无录音不能提交。
- 后置结果: 展示转写状态或结果，转写完成后才可复盘；刷新不新建任务。
- 显示数量限制: 录音由服务端保存；音频格式、时长与语言按模型接口和实测确认。
- 排序规则: 按原始说话顺序。

- 标题: 复盘请求与快照

- 数据来源:

## reviewComparison
- 标题: 查看复盘结果
- 模块说明: 查看整体总结及实战和复盘的五维评分对比。
- 数据来源:

| 页面内容 | 来源 | 关联／处理方式 |
| --- | --- | --- |
| 整体复盘 | AI根据演练目标和实际通话转写生成 | 概括达成情况、优点、问题和建议 |
| 五维评分 | 对比演练的评分和AI复盘的评分 | 每项0–10分；若无演练评分，则只展示复盘评分，隐藏相关图例和下方的具体分值 |

- 失败提示: 复盘生成失败，请重试。。

- 展示顺序: 五维评分雷达图在上，文字总结在下。

- 总结字数限制: 文字总结不超过500字。

- 评分对比: 同一雷达图叠加关联演练评分与复盘评分，固定相同五维顺序及0–10分刻度。蓝色虚线表示演练评分，绿色实线表示复盘评分，图上方明确显示颜色图例，图下方分组展示两组分数。
- 对比数据来源: 演练评分取本次关联演练的已保存总结评分，复盘评分取本次复盘结果；不重新调用模型生成演练评分。缺失评分显示暂无评分，仅绘制有效点，不将空值当作0分。

## 已确认的数据来源分类

客户端静态内容包括页面与栏目名称、字段标签、占位提示、场景名及图标、场景初始模板、普通按钮文案与图标、+86和拨号键盘、空态提示、固定操作提示、中文状态名称、菜单名、产品图标及默认头像、仅原型使用的条件标签。

静态标签不表示实际值静态：目标回顾取确认快照后按静态格式拼接；恢复弹窗取服务端公开编号替换占位；会员文案根据实际权益显示；套餐名称映射实际StoreKit商品和价格；注销按钮固定标签配动态倒计时；协议入口固定但正文／地址／版本可更新；提交标签固定但禁用状态根据输入计算。

本地字数统计、倒计时、计时、格式化与可点击判断均为客户端动态计算，不归静态。账号、会员到期、服务端额度、电话记录时间、实际状态、转写原文、AI结果、系统通讯录数据和授权选择继续保留真实来源。

### 通话录音播放与转写标签
- 录音待同步时不展示播放器；录音已生成后，在待转写、转写中、转写失败和转写完成状态均可播放，与转写功能独立。
- 展示不可拖动的进度条、当前播放时间、总时长及播放／暂停、停止按钮。停止后回到开头，离开详情页停止播放。
- 转写按分句展示“说话人编号（性别）［情绪］”、时间和正文。性别、情绪读取识别结果，缺失显示未知。
- 当前原型内置合成示例录音；正式接入使用服务端返回的录音地址。

- 订阅页的自动续费协议、用户协议、隐私政策，以及账号注销协议，均打开独立H5页面展示，不使用弹窗。
- 原型在新浏览器标签打开；iOS客户端进入新的H5容器页面，返回后保留原页面状态。
- 账号注销协议页保留阅读倒计时与继续按钮，正式注销操作仍需调用服务端接口；原型不执行真实注销。

### AI对话结束后的页面刷新
- 用户点击结束对话后，停止语音连接并保存本次有效演练记录，返回演练首页并重新渲染首页及最近演练列表。
- 不再自动进入演练结果页；在演练记录中主动点击生成总结与评分后查看。无有效对话时也返回首页，不生成空演练记录。
- 首页刷新为数据与界面刷新，保留本次记录，不通过整页重载清空原型内存数据。

### 复盘等待生成与刷新
- 分析任务处理中或任务尚未返回分析结果时，展示“复盘等待生成”，暂不展示总结或评分雷达图。
- 底部提供“刷新状态”按钮。正式接入查询当前任务状态，不重复创建分析任务；处理中保留等待页，成功展示结果，失败展示重试入口。
- 原型提供预约改期的固定示例：首次进入复盘结果先等待生成，3秒后自动展示整体复盘及五维评分；切换等待生成选项可重播。示例数据仅用于展示，正式结果由服务端返回。

### 演练总结待生成
- 演练结果页的待生成状态仅作用于“演练总结”模块；目标回顾和转写记录始终按已有内容正常显示。
- 总结未返回时展示“演练总结待生成”和刷新状态按钮，不展示空评分或雷达图。
- 刷新查询当前总结任务，不重新创建任务；成功后仅更新总结模块，保留阅读位置。原型刷新保留当前状态，不虚构生成结果。
- 上方提供“演练总结：正常／待总结／生成中／失败”预览切换。

### 弹窗独立查看入口
- 原型左侧“弹窗”分组包含“首次协议弹窗”和“400拨号提示”，进入即展示对应弹窗，关闭后可点击“重新打开”。
- 这两个入口仅用于评审查看，不依赖首次进入记录或“不再提示”设置，也不写入真实授权及提示偏好。正常业务入口沿用原有触发与保存规则。


## phoneBinding
- 标题: 绑定手机号
- 模块说明: “我的”提供绑定手机号入口；实战点击拨打后先校验手机号是否绑定，再校验会员。未绑定进入绑定页，输入手机号和验证码，校验成功后绑定当前账户。已绑定时沿用相同界面，手机号输入栏禁用，隐藏验证码及绑定按钮，不提供解绑入口。
- 数据来源:

| 页面内容 | 来源 | 关联／处理方式 |
| --- | --- | --- |
| 绑定状态及手机号 | 服务端当前账户的绑定信息 | 未绑定允许填写；已绑定展示绑定手机号并禁用输入 |
| 待绑定手机号 | 用户输入 | 用于获取验证码及提交绑定 |
| 验证码 | 用户输入的短信验证码 | 服务端校验验证码后执行绑定 |

- 前置条件: 用户从“我的”进入，或实战拨打时尚未绑定手机号。
- 后置结果: 从“我的”绑定成功后展示已绑定状态；从实战进入并绑定成功后，继续校验会员再进入拨号流程。
- 显示数量限制: 当前账户展示1个绑定手机号，不提供解绑入口。
- 排序规则: 手机号、验证码、确认绑定；已绑定隐藏验证码和确认绑定。
