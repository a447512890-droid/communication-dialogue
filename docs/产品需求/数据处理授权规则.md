# 第三方数据处理授权规则

## 确认方案

首次进入App功能界面显示“语音与数据处理说明”，说明向千问或豆包提交必要语音、录音、文字及目标信息，用于语音演练、转写、总结和复盘。按钮“暂不同意／同意并继续”，关闭或返回按未同意处理，不默认勾选。授权说明版本变化需重新确认。

拒绝不影响浏览、填写目标及查看已有记录；未同意时不发送第三方AI请求。用户再次使用AI功能时，重新展示同一说明弹窗；同意后由用户再次确认原操作。

取消独立授权管理页面及入口，不展示授权状态、记录时间和版本卡片。授权选择及版本仍在内部保存，用于请求前校验。麦克风、通讯录及录音权限分别申请。

## 文案

使用AI演练、转写和复盘时，必要的语音、录音、对话及目标将发送至千问或豆包，仅用于提供相应功能。

录音仅在点击“开始转写”后提交。暂不同意仍可浏览、填写目标和查看已有记录，AI功能暂不可用。

弹窗最大宽度328px；正文13px，协议链接分两列。长内容单独滚动，底部选择按钮保持可见。不在弹窗展示麦克风、通讯录和录音权限说明。

## 记录与执行

| 字段 | 来源 | 规则 |
| --- | --- | --- |
| status | 用户同意、暂不同意或撤回操作 | accepted／declined／withdrawn；未记录为unknown |
| version | 当前授权说明版本配置 | 版本不一致不认定已有同意 |
| recorded_at | 当前原型由客户端操作时记录UTC时间 | 仅内部保存，不在页面展示 |

当前浏览器使用本机存储模拟；正式账号服务需保存服务端受理时间、说明版本和授权操作，跨设备由服务端校验。存储失败不伪称已持久化，浏览器清理或新设备会再次提示。当前拒绝／撤回门禁已覆盖千问实际请求入口及ASR／复盘演示入口；真实服务仍须服务端校验，不能仅依赖前端。
