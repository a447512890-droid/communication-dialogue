# 会员功能限制规则

## 会员功能清单

| 功能 | 非会员 | 有效会员 | 限制及处理方式 |
| --- | --- | --- | --- |
| AI对话演练 | 不可使用 | 每用户每日累计最多60分钟 | 用尽后停止当前演练并保留已有记录；提示：您今日的演练时长已用完，请明天再来。 |
| 实战呼叫 | 不可使用 | 可使用 | 见[400呼叫限制规则](400呼叫限制规则.md) |
| 实战复盘 | 不可使用 | 每用户每日最多发起10次 | 按发起次数计数，不按成功完成次数计数；超出提示：今日复盘次数已用完，请明天再来。 |
| 录音转写 | 不可使用 | 每用户每日最多发起10次 | 按用户当日发起的转写总次数计数，不是每条录音10次；超出提示：今日转写次数已用完，请明天再来。 |

## 权益校验

- 有效会员由服务端校验；非会员发起上述功能时跳转订阅充值页，不创建相应任务。
- 额度按北京时间每自然日统计，次日00:00重置。演练时长按同一用户当日多次演练累计计算。
- 复盘与转写分别独立计数，各每日最多发起10次。任务一经发起即计数，失败或未完成不返还；重新发起或重试新任务再次计数。仅查询、刷新已有任务状态不计为发起。
- 录音转写按同一用户对所有录音发起的请求合计，不按单条录音分别分配额度。
- 服务端前置校验拒绝且未创建任务的请求不计数；相同请求幂等处理，避免重复计数。达到10次后禁止发起第11次。
- 上述额度和会员规则均由服务端配置、校验及计数，不依赖客户端执行。
- 会员身份不豁免手机号绑定或400呼叫限制；购买或恢复购买后重新获取服务端权益。
