## 当前业务

演练设定目标、确认后连接千问，结束收齐转写后由Seed 2.1生成overview/suggestions总结。真实电话默认只保存有效录音，用户点击开始转写后才提交豆包ASR；转写完成后才可复盘。复盘先选实战电话，再手选关联演练并确认，不自动配对。系统通讯录仅使用iOS原生选择页，无App联系人资料。

## 本地运行

在项目根目录运行`node qwen-ai-practice-demo/server.mjs`，访问http://127.0.0.1:8766/。长期密钥仅在本地服务端.env读取，不进入前端或导出包。说明面板直接读取需求说明.md，打开时每约2秒检查保存变更，不需要生成JS。

当前真实接入为本地千问WebRTC演练；其它状态、支付、录音、ASR、账号与AI分析均不可因演示按钮判作已接入，详见能力清单。

## 静态导出与历史

运行`python3 scripts/build_pages.py --output 新的空目录`只生成可查看的静态文件，不部署、不包含密钥、不带旧截图。真实语音需要本地Node接口，静态托管不提供该接口。已取消页面的旧确认资料及生成工具在docs/历史资料/2026-10-19一致性清理前，仅用于追溯，不作为开发依据。当前BRD及过时商店截图按用户确认移除。


## 原型操作与维护

左侧导航选择页面，中间为手机原型，右侧为需求说明；状态预览标签位于手机上方。页面主要操作固定底部，内容单独滚动。需求说明按 `## moduleKey` 关联，保存MD后打开的面板约2秒更新。必填无效按钮置灰。

演练流程：选择场景 → 填写目标 → 确认并开始 → AI对话 → 结束 → 总结 → 结果。非会员可填写，最后开始时进入订阅充值。复盘仅提交所选目标和实际通话转写，展示整体复盘、五维评分列表及雷达图。

## Git与发布范围

保留当前页面依赖、需求规则、AI提示词和运行说明。`docs/历史资料/`、`docs/核对清单/`、`docs/协作规范/`及一次性文档清理记录留在本地，排除Git上传。已被跟踪的相关文件从Git索引移除，磁盘资料保留；已有历史提交不被重写。

Pages导出使用明确文件清单，不扫描整个文档目录；排除历史资料、核对清单、过程记录、密钥及环境文件。`原型/README.md`及独立`演练流程.md`已合并至本文件和业务流程图。

演练页与独立demo共用`/api/realtime-sdp` WebRTC连接：会话配置确认后启用麦克风，语音和文字实时返回；失败原因显示在演练页，可在底部重新连接。请从本地Node服务入口打开，静态Pages无法提供语音代理。

兼容预览入口：`python3 scripts/preview.py --port 8765`现在也启动同一Node语音服务，支持演练POST接口；不再使用Python静态服务器承载演练。
